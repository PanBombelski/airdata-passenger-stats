# airtraffic-anomalies

Zobacz [wersję po angielsku](README.md).

Aplikacja internetowa do wykrywania nietypowych tras lotniczych nad Polską, oparta na publicznych danych z OpenSky Network.

## Idea

Trasy lotnicze zwykle przebiegają podobnie. Projekt zbiera pozycje samolotów w czasie, buduje średnią trasę dla wybranej pary lotnisk (np. Rzeszów–Gdańsk) i wskazuje loty, które najbardziej od niej odbiegają.

## Aktualny etap

**Etap 1: Makiety (w toku)**
- Mapa strony z co najmniej czterema sekcjami
- Makieta desktopowa (1200 px)
- Makieta mobilna (390 px)
- Opis interakcji użytkownika

## Planowane etapy

2. Implementacja: prototyp w HTML, CSS i JavaScript
